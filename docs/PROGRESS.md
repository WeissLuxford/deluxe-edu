## Как устроен перенос (чтобы не вспоминать)

- Новое — в `src/design/` (токены, компоненты, layout) и в `features/<домен>/*.module.css`
- Тексты v2 — `src/locales/*/app.json` (новые namespaces с суффиксом Page / Flow),
  старые namespaces в `common.json` удаляются, когда их последний потребитель ушёл
- Переводы добавляются deep-merge'ем словаря `{ru:{…},en:{…},uz:{…}}` в три app.json
  (маленький python-скрипт; тест `tests/content.test.ts` ловит рассинхрон ключей)
- Группа `(focus)` — экраны без шапки/подвала (тест уровня, пробный урок)
- Проверка: `npm run check`; превью — dev-сервер `deluxe-edu` из `.claude/launch.json`
- ⚠ Не запускать `next build`, пока работает dev-сервер: он перезаписывает `.next`, и
  localhost отдаёт Internal Server Error. Лечение: остановить сервер → `rm -rf .next` → запустить
- Под учеником сам не логиниться (локалка пишет в прод) — просить владельца войти в панели
- Коммиты мелкие, по одному куску; пуш только по команде владельца (на вечер 01.10 — ~30 коммитов не запушено)
- Новая страница = артборд холста + тексты на «ты» в app.json (ru/en/uz) + Reveal/плавность + удалить старое
