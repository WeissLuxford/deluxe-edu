# Картинки сайта

Сюда кладём изображения. Путь в коде и в админке пишется от корня сайта:
файл `public/media/courses/beginner-grammar.webp` указывается как
`/media/courses/beginner-grammar.webp`.

## Две разные вещи

**Декор маркетинговых страниц** задаётся в `src/content/media.json` по ключу
слота. Пока в ключе пустой `src`, на месте картинки видна пунктирная рамка с
именем слота — сразу понятно, куда класть файл, и вёрстка не разъезжается.

**Обложки курсов, модулей и уроков** приходят из базы: путь вводится в админке в
карточке курса или урока. Если файла по этому пути нет, вместо него рисуется
плашка с цветом уровня — сломанной картинки посетитель не увидит.

## Договорённости

- Формат `.webp`, для логотипов и простых фигур `.svg`
- Обложка курса и урока — соотношение 16:9, ширина от 640px
- Портреты преподавателей — 4:5
- Имя файла латиницей, слова через дефис
- В учебной зоне и админке декоративных картинок нет: там они мешают работе
- Исключение — личный кабинет: аватарки (`src/content/avatars.json`) и ачивки
  (`src/content/achievements.json`) размечены по тому же принципу (пустой `src`
  → аккуратная заглушка вместо сломанной картинки), но это не декор, а
  персонализация, поэтому они здесь осознанно допущены. Картинки квадратные,
  `.png` с прозрачностью (не `.svg`), пути кладём в `public/media/avatars/` и
  `public/media/achievements/`

Папки заводим по разделам: `home/`, `about/`, `courses/`, `lessons/`, `team/`,
`avatars/`, `achievements/`.

## Где сейчас размечены слоты

| Ключ | Где на сайте |
|---|---|
| `home.format.preview` | Главная, блок «Как устроен урок» — картинка справа от шагов |
| `home.mentor.portrait` | Главная, блок про преподавателя — портрет |
| `home.cta.side` | Главная, призыв к действию — декор слева |
| `about.hero.side` | «О нас», первый экран — декор справа |
| `courses.hero.side` | Каталог, шапка — декор справа |
| `contacts.hero.side` | «Контакты», первый экран — декор слева |
| `course.default.cover` | Запасная обложка курса |

Декоративные слоты (`*.side`) не показываются на экранах уже 1100px — на телефоне
они бы только отнимали место.
