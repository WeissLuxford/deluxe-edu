# Deluxe Edu (Vertex)

Учебная платформа: курсы, уроки с видео/конспектом/тестом, живые занятия, оплата.
Продакшн — [vertexedu.uz](https://vertexedu.uz) (Vercel).

## Стек

| Что | Чем |
|---|---|
| Фреймворк | Next.js 15, App Router, React 19 |
| База | PostgreSQL (Neon) через Prisma |
| Авторизация | NextAuth, вход по телефону + пароль (JWT-сессии) |
| Языки | next-intl: `ru`, `uz`, `en` |
| Стили | Tailwind v4 + CSS-переменные |
| SMS (OTP) | Eskiz.uz |
| Оплата | Payme, Click (в разработке) |

## Запуск

```bash
npm install
cp .env.example .env    # заполнить значения
npx prisma migrate dev  # накатить схему
npm run seed            # тестовые курсы
npm run dev
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на localhost:3000 |
| `npm run build` | Прод-сборка (сначала `prisma generate`) |
| `npm run seed` | Заполнить базу курсами из `prisma/seed.ts` |
| `npm run db:migrate` | Создать и применить миграцию |
| `npx tsc --noEmit` | Проверка типов |

## Переменные окружения

Список и описание — в [`.env.example`](.env.example).

**`.env` в git не коммитится никогда.** Локальные значения живут в `.env`,
боевые — в панели Vercel (Settings → Environment Variables). Это два разных
хранилища, файл на компьютере на продакшн не влияет.

Единственная переменная, где значения намеренно разные: `NEXTAUTH_URL`
(локально `http://localhost:3000`, на проде `https://vertexedu.uz`).

## Структура

```
src/
  app/
    [locale]/        страницы (локаль в пути: /ru/courses)
    api/             серверные роуты
  features/          код по фичам: courses, dashboard, home, streams, ui...
  lib/               auth.ts, db.ts (Prisma), sms.ts, zoom.ts
  locales/           переводы ru/uz/en
  i18n/              настройка next-intl
prisma/
  schema.prisma      модель данных
  migrations/        история изменений схемы — обязана быть в git
  seed.ts            наполнение базы
```

## Правила по безопасности

Их нарушение уже один раз стоило утечки всех ключей, поэтому коротко:

1. **Секреты не попадают в git.** Ни в `.env`, ни в коде, ни в комментариях.
2. **`userId` берётся только из сессии** (`getServerSession`), никогда из тела
   запроса. Иначе любой может действовать от чужого имени.
3. **Оценки и проверки считает сервер.** Всё, что пришло из браузера, — это
   пожелание пользователя, а не факт.
4. **Доступ к платному контенту проверяется на сервере** через активный
   `Enrollment`, а не скрытием кнопок в интерфейсе.
5. **Тестовых и отладочных роутов в продакшне нет.** Никаких `/api/test-*`
   и `/api/dev/*`.
